# indicat-sticky-notes

Простые стикеры для рабочего стола Linux на Python и GTK3 с иконкой в системном трее.

Идея навеяна [Sticky](https://github.com/linuxmint/sticky) из Linux Mint. Это независимая реализация, код оригинала не использовался.

## Возможности

- Заметки в отдельных окнах без рамки: скруглённые углы, мягкая тень, цветная шапка. Перетаскиваются за верхнюю панель, размер меняется за правый нижний угол
- 6 цветов (кнопка `●` в шапке), подсказка в пустой заметке
- Автосохранение текста, цвета, позиции и размера
- Иконка в трее: новая заметка, показать/скрыть все, выход (клик по иконке переключает видимость)
- Один экземпляр приложения: повторный запуск показывает уже созданные заметки

Закрытие окна заметки только прячет её. Удаляется заметка кнопкой `×`.

Скругление и тень работают при включённом композитинге (в MATE: «Параметры окон» → «Использовать композитинг»). Без него заметки рисуются прямоугольными, без тени.

## Требования

- Python 3.9+
- GTK 3 и PyGObject (в Debian/Ubuntu/Mint: `python3-gi gir1.2-gtk-3.0`, в Fedora/RED OS: `python3-gobject gtk3`)

## Запуск

```bash
./run.sh
```

или `python3 -m indicat_sticky_notes`.

Чтобы получить кнопку запуска, создайте ярлык. Он появится в корне проекта (`Стикеры.desktop`, запускается двойным щелчком) и в меню приложений:

```bash
./create-shortcut.sh
```

Заметки хранятся в `~/.local/share/indicat-sticky-notes/notes.json`.
