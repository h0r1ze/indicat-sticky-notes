# indicat-sticky-notes

Стикеры для рабочего стола Linux на Python и GTK3 с иконкой в системном трее.

Идея навеяна [Sticky](https://github.com/linuxmint/sticky) из Linux Mint. Это независимая реализация, код оригинала не использовался.

## Возможности

**Заметки**
- Окна без рамки: скруглённые углы, мягкая тень, цветная шапка. Перетаскиваются за шапку, размер меняется за правый нижний угол
- Цвета (кнопка `●`): 8 основных (в том числе два тёмных), дизайнерская палитра из 32 оттенков и «Свой цвет…» с редактором. Цвет текста подбирается под фон автоматически (контраст не ниже 4.5 по WCAG AA)
- Форматирование: **жирный** `Ctrl+B`, *курсив* `Ctrl+I`, подчёркнутый `Ctrl+U`, зачёркнутый `Ctrl+Shift+X`. Работает и в русской раскладке
- Чекбоксы: кнопка ☑ или `Ctrl+L`, набор `[ ] ` превращается в ☐, Enter продолжает список (на пустом пункте завершает), клик по квадратику ставит галочку, выполненные пункты зачёркиваются
- Заголовок заметки, прозрачность (нужен композитинг), размер шрифта (`Ctrl++`, `Ctrl+-`, `Ctrl+0`, `Ctrl` + колесо мыши) для каждой заметки отдельно
- Закрепление поверх всех окон (📌)
- Сворачивание в одну шапку: двойной щелчок по шапке
- Меню `⋯` (или правая кнопка по шапке): заголовок, формат, шрифт, прозрачность, группа, «Сохранить как файл…», «В корзину»

**Порядок**
- Менеджер заметок: поиск по заголовкам и тексту, фильтр по группам, показать/скрыть заметку или целую группу, подсветка найденного при открытии заметки
- Группы (метки): раскладывайте заметки по группам и показывайте/скрывайте группу целиком (менеджер или трей)
- Корзина: удалённые заметки хранятся 30 дней (настраивается), их можно восстановить. Пустые заметки удаляются без корзины

**Данные**
- Резервные копии: автоматическая раз в сутки при запуске, ручная и восстановление (меню «Резервные копии» в трее); последние 30 хранятся в `~/.local/share/indicat-sticky-notes/backups`. Перед восстановлением делается отдельная копия
- Экспорт: все заметки одним Markdown-файлом (с форматированием и чекбоксами), отдельные `.txt` в папку, одна заметка в файл
- Импорт: `.txt`, `.md`, свой экспорт, резервные копии и **Mint Sticky** (`~/.config/sticky/notes.json`: текст, цвет, группы, жирный/курсив/подчёркнутый/зачёркнутый и чекбоксы)
- Синхронизация между компьютерами: в настройках выберите папку, которую синхронизирует Syncthing, Nextcloud, Яндекс.Диск и т. п. Правки с других компьютеров подхватываются автоматически, при конфликте побеждает более новая правка; положение и размер окон у каждого компьютера свои
- Повреждённый файл заметок не затирается: он откладывается в сторону, а приложение сообщает об этом

**Система**
- Иконка в трее: новая заметка, поиск, менеджер, показать/скрыть все, группы, обмен данными, копии, автозапуск, настройки
- Глобальные горячие клавиши (X11): новая заметка `Ctrl+Alt+N`, показать/скрыть все `Ctrl+Alt+S` (меняются в настройках). В Wayland приложение не может перехватывать клавиши вне своих окон, поэтому там они недоступны
- Тёмная тема интерфейса (настройки), цвет и шрифт новых заметок
- Автозапуск при входе (переключатель в трее и в настройках)

Закрытие окна заметки только прячет её (состояние «скрыта» запоминается, вернуть можно из менеджера или трея). Скругление и тень работают при включённом композитинге (в MATE: «Параметры окон» → «Использовать композитинг»), без него заметки рисуются прямоугольными.

## Требования

- Python 3.9+
- GTK 3 и PyGObject (Debian/Ubuntu/Mint: `python3-gi gir1.2-gtk-3.0`, Fedora/RED OS: `python3-gobject gtk3`)

## Запуск из исходников

```bash
./run.sh
```

или `python3 -m indicat_sticky_notes`.

Чтобы получить кнопку запуска, создайте ярлык. Он появится в корне проекта (`Стикеры.desktop`, запускается двойным щелчком) и в меню приложений:

```bash
./create-shortcut.sh
```

Приложение запускается в одном экземпляре: повторный запуск просто показывает заметки. Чтобы запустить обновлённую версию, сначала завершите старую (трей → «Выход»).

## Установка пакетом

**Debian, Ubuntu, Linux Mint** (нужны `python3-setuptools` и `dpkg-deb`):

```bash
./packaging/build-deb.sh
sudo apt install ./build/indicat-sticky-notes_*_all.deb
```

**Fedora, RED OS** (spec лежит в `packaging/rpm/`; нужны `rpm-build`, `python3-devel`, `python3-setuptools`):

```bash
git archive --prefix=indicat-sticky-notes-0.2.0/ -o ~/rpmbuild/SOURCES/indicat-sticky-notes-0.2.0.tar.gz HEAD
rpmbuild -ba packaging/rpm/indicat-sticky-notes.spec
```

После установки приложение запускается командой `indicat-sticky-notes` или из меню приложений. На GitHub сборка `.deb` и тесты идут автоматически (`.github/workflows/ci.yml`).

## Где лежат данные

| Что | Где |
|---|---|
| Заметки | `~/.local/share/indicat-sticky-notes/notes.json` (или выбранная папка синхронизации) |
| Резервные копии | `~/.local/share/indicat-sticky-notes/backups/` |
| Настройки | `~/.config/indicat-sticky-notes/settings.json` |

## Тесты

Логика проверяется обычными тестами, интерфейс (включая настоящие нажатия горячих клавиш через XTest) — в виртуальном X-сервере:

```bash
xvfb-run -a python3 -m unittest discover -s tests -t .
```

Без дисплея интерфейсные тесты пропускаются:

```bash
python3 -m unittest discover -s tests -t .
```
